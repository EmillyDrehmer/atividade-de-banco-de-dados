# atividade-de-banco-de-dados
Atividades da UC Sistemas de Armazenamento de Dados para Automação 

Atividades de Banco de Dados

Repositório criado para armazenar as atividades, exercícios, roteiros e exemplos desenvolvidos durante a Unidade Curricular Sistemas de Armazenamento de Dados para Automação.

Conteúdo

Neste repositório estão disponíveis:

Modelos Entidade-Relacionamento (MER);
Scripts SQL de criação de bancos de dados;
Scripts de população de tabelas;
Consultas SQL;
Roteiros de atividades;
Exercícios propostos em aula.

Objetivo

Organizar e centralizar os materiais produzidos durante a disciplina, facilitando consultas futuras, estudos e revisões dos conteúdos relacionados a banco de dados e SQL.


Autora

Emilly Miranda Drehmer

Observação

Este repositório possui finalidade exclusivamente acadêmica e educacional, sendo utilizado para o armazenamento das atividades desenvolvidas durante a UC de Sistemas de Armazenamento de Dados para Automação.
